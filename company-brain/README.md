# Infinity Power Company Brain

> Maintained by: Infinity Power Executive Secretary (INF-191)
> Company: Infinity Power 89 / EastGrid Systems

## Purpose

This is the central knowledge repository for Infinity Power. All important company decisions, meetings, daily logs, and contacts are recorded here.

## Rules

- **Never overwrite historical data** — append only; use new files or new sections
- **Daily logs** — one file per day: `daily-logs/YYYY-MM-DD.md`
- **Meetings** — one file per meeting: `meetings/YYYY-MM-DD-topic.md`
- **Decisions** — logged in `decisions/YYYY-MM.md` by month
- **Goals** — updated in `goals/company-goals.md`
- All changes committed to Git and pushed to GitHub

## Structure

```
company-brain/
├── README.md            — this file
├── daily-logs/          — daily status log, one file per day
├── meetings/            — meeting summaries
├── decisions/           — decision log by month
├── goals/               — company goals and OKRs
├── contacts/            — key contacts and leads
└── projects/            — project status snapshots
```
